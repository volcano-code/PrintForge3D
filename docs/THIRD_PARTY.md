# Third-party components and data

PrintForge3D source is MIT-licensed. This does not relicense third-party code, pretrained weights, or datasets.

Before downloading, redistributing, or using any checkpoint, record its repository and exact revision, source-code license, checkpoint license, dataset terms, attribution requirements, and commercial-use restrictions.

The learned reconstruction adapter must use an explicitly commercial-use-compatible checkpoint/license path. Do not silently substitute a non-commercial checkpoint. COLMAP, Open3D, pycolmap, PyTorch, and other dependencies retain their own licenses; consult upstream license files before packaging.

Dataset records must retain source, license, attribution, and restrictions. Large datasets and model weights are not committed.
